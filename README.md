# 💰 Kalkulator Pendapatan Bersih
Aplikasi Python sederhana untuk menghitung laba usaha dengan akurat.

## 🚀 Fitur
- Perhitungan pendapatan bersih otomatis.
- Tampilan "Badge" yang rapi.
- Anti-error format angka.

## 🛠 Cara Jalankan
1. Pastikan sudah instal Python.
2. Jalankan perintah: dengan
3. Masukkan angka bulat (Contoh: 10000).
